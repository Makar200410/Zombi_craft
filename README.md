# Zombi Craft — Осада нежити

3D-игра для браузера, ПК и Android: воксельная песочница как в Minecraft, строительство деревни как в Clash of Clans, живые жители как в моде Millénaire, оружие и магия, исследования в лаборатории и ночные волны зомби.

## Как играть
- **Android (APK):** https://github.com/Makar200410/Zombi_craft/releases/tag/apk-latest — скачайте `ZombiCraft.apk` и установите (разрешите установку из неизвестных источников).
- **Браузер:** включите GitHub Pages (Settings → Pages → Source: GitHub Actions), игра будет по адресу `https://makar200410.github.io/Zombi_craft/`.
- **Локально:** `npm install && npm run dev`.

## Управление (ПК)
WASD — ходьба, Пробел — прыжок, Shift — бег, ЛКМ — атака/добыча, ПКМ — поставить блок/использовать, 1–9 и колесо — выбор предмета, V — вид от 1/3 лица, Tab/B — режим командования (стройка, жители, исследования), Q/E — поворот камеры в режиме командования.
На телефоне — джойстик слева, обзор пальцем справа, кнопки действий.

## Что есть
- Процедурный мир 192×192: леса, горы со снегом, озёра, пещеры с рудами (уголь, железо, золото, кристаллы маны), «проклятые» земли по краям.
- Плавное освещение, тени, свет факелов ночью, смена дня и ночи, процедурный звук и музыка.
- Деревня: ратуша, дома, лесопилка, ферма, шахта, склад, лаборатория, кузница, башня мага, дозорная башня, казармы, стены. Жители реально рубят деревья, копают карьер, сеют и собирают пшеницу, строят дома по блокам.
- Оружие: мечи, топоры, лук, арбалет, мушкет, мушкетон, бомбы; магия: огонь, лёд, молнии, лечение, метеоры.
- Зомби: обычные, бегуны, громилы, плевальщики, подрывники, босс-некромант; волны каждую ночь, ломают стены, горят на рассвете.
- Дерево исследований из 16 технологий, автосохранение.
